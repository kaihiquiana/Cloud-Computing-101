# Microsoft Azure

## Brief Overview
Azure was launched in 2010 by Microsoft. It works really well with Windows, Microsoft 365, and other tools that many schools and offices already use.

## Global Infrastructure
Azure has the most regions of any cloud provider — over 60 regions worldwide. That means they're available in more countries.

## Cloud Management Console
You manage Azure through the Azure Portal at portal.azure.com. It's easy to use if you already know Microsoft products.

## Four Core Services
1. **Azure Virtual Machines** — create Windows or Linux virtual computers.
2. **Azure Blob Storage** — store unstructured data like files and media.
3. **Azure Virtual Network** — create your own private network space.
4. **Azure SQL Database** — fully managed database service.

## Three Advantages
- Works perfectly with Windows Server, Office 365, and Active Directory.
- Good security and compliance for schools and government.
- Easy to move existing Windows systems to the cloud.

## Common Uses
- Moving school or office servers to the cloud
- Running business apps made with .NET
- Hybrid setups where some things stay on local servers
