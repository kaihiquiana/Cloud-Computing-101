## Questions

**1. Which cloud provider offers the broadest range of services?**
AWS seems to have the most services overall. They started earliest and have been adding features longer, so they cover almost every use case you can think of.

**2. Which provider best integrates with Microsoft technologies?**
Azure is definitely the best for Microsoft products. Since they are both from Microsoft, Windows Server, Office 365, and Active Directory all work together smoothly.

**3. Which provider is strongest in AI and Kubernetes?**
Google Cloud is strongest here. They created Kubernetes and have the best tools for AI and machine learning because Google does so much research in those areas.

**4. Which cloud platform would you personally choose and why?**
I would probably choose AWS because it has the most tutorials and help online, which makes it easier to learn as a student. But if I were working at a school or office that uses Windows everywhere, I would pick Azure instead.
