# Google Cloud Platform (GCP)

## Brief Overview
GCP was launched publicly in 2013. It's built on the same infrastructure Google uses for its own services like YouTube and Google Search. They are especially strong in data and AI.

## Global Infrastructure
They have 34 regions worldwide with a high-speed private network. This makes their connections fast.

## Cloud Management Console
Accessible at console.cloud.google.com. The interface feels clean and modern.

## Four Core Services
1. **Google Compute Engine** — high-performance virtual machines.
2. **Google Cloud Storage** — fast and scalable storage.
3. **Google VPC** — global virtual networking.
4. **BigQuery** — analyze huge amounts of data quickly.

## Three Advantages
- Best tools for data analysis and machine learning.
- They created Kubernetes, so they know it best.
- Their network is fast and pricing is competitive.

## Common Uses
- AI and machine learning projects
- Data science and big data processing
- Apps that need to scale globally
